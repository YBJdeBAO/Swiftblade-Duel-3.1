# Swiftblade Duel 3.1

🌐 **语言：** [English](README.md) | 中文

一款基于浏览器的 1v1 骑士对决游戏，以单页 HTML5 Canvas 的形式实现。两名骑士在紧凑的竞技场中进行战斗，包含移动、攻击、格挡、闪避、生命值、屏幕震动、粒子反馈和连局胜场统计。

3.1 版本在基础对决之外加入了更多事件式机制，包括追踪飞剑、滚落重头和戏剧化的即死爆炸效果。

## 🚀 在线体验

https://ybjdebao.github.io/Swiftblade-Duel-3.1/

## ✨ 功能特性

- 单文件静态游戏，无需构建步骤。
- PvE 练习模式，可与简单 AI 对手对战。
- PvP 本地双人模式，支持两名玩家共用键盘。
- 金色骑士与蓝色骑士拥有独立生命条。
- 包含攻击、格挡、闪避、受击硬直、冷却时间和低血量警告状态。
- 胜利结算界面支持跨局累计胜场。
- 使用 Canvas 实现粒子、屏幕震动、打击反馈和街机风格 UI。
- 3.1 版本额外加入追踪飞剑、滚落重头和即死爆炸等特殊事件。

## 🕹️ 玩法说明

1. 打开在线体验页面，或在本地启动静态服务。
2. 选择 Practice Match 进入 PvE，或选择 Duel Match 进入 PvP。
3. 通过移动控制距离。
4. 接近对手后发动攻击。
5. 使用格挡抵御进攻，或用闪避躲开伤害。
6. 将对手生命值降为 0 即可获胜。

## 🛠️ 本地运行

本项目使用原生 HTML、CSS 和 JavaScript 编写，不需要包管理器或构建工具。

```bash
python3 -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

也可以直接用浏览器打开 `index.html`，不过使用本地服务器会更接近正式访问环境。

## 🧩 技术说明

- 使用 Canvas 2D API 进行渲染。
- 游戏状态、角色、粒子、飞行物和特殊事件均使用原生 JavaScript 实现。
- 样式主要由内联 CSS 和 CDN 版 Tailwind 组成。
- 游戏主要面向桌面键盘操作。
